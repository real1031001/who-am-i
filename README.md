# WHO AM I — 사교 클럽

3–8명이 서로 비밀 인물을 지정하고 질문으로 자신의 정체를 맞히는 실시간 웹게임입니다.

## 실행

Node.js 22 이상. 외부 패키지 의존성이 없습니다.

```sh
npm test
npm start
```

기본 포트는 3000이며 `PORT` 환경변수를 지원합니다. `/`는 실제 멀티플레이, `/preview`는 디자인 체험판, `/health`는 상태 확인입니다.

## 배포

- GitHub에 이 저장소를 업로드합니다.
- Render Web Service: Node, Singapore, Free, branch `main`.
- Build Command: `npm test`
- Start Command: `npm start`
- Health Check Path: `/health`
- 단일 인스턴스 구성. 데이터베이스나 비밀 환경변수는 필요하지 않습니다.

방·제시어·세션은 서버 메모리에 저장됩니다. 서버 재배포·재시작 시 진행 중인 방은 초기화됩니다. 브라우저의 새로고침/일시적 접속 해제에는 60초 재접속을 지원하지만, 서버 재시작 복구와는 다릅니다. 공개 운영 규모 확대 전에 영속 저장소와 배포 중 세션 복원을 추가해야 합니다.

## 승인 규칙

- 대기방: 16종 프로필 중복 가능, 닉네임 설정, 전원 준비 후 방장 시작. 시작 시 순서를 무작위로 정하고 고유 번호 부여.
- 왼쪽 목록: 본인 녹색 형광 외곽선, 현재 차례 빨간 테두리. 본인 차례에는 두 표시를 함께 사용. 답변자가 중앙에 있어도 차례 소유자는 유지.
- 제시어: 한 명씩 다른 유저가 15초 제안 → 15초 익명 투표. 전원 완료 시 조기 진행. 본인 제안에도 투표 가능. 동일 문자열 후보 통합. 최다 득표 동점은 무작위.
- 미제출/미투표 기권. 후보 0개는 15초 재시도, 1개는 즉시 확정, 전원 기권 시 전체 후보 중 무작위.
- 전원 선정 후 10초 카운트다운. 첫 바퀴는 질문만. 두 번째부터 자기 차례 10초 내 질문 또는 정답 제출. 시간 초과는 패스.
- 질문은 답변자 1명 지목, 답변 최대 20초, 공개 5초. 관전자도 답변 가능.
- 정답은 입력 앞뒤 공백만 제거하고 제시어와 일치하면 자동 인정. 불일치 시 나머지 전원 10초 투표. 시작 당시 대상 인원의 반수 이상(ceil(N/2))이면 인정. 관전자 포함, 미투표와 도중 퇴장은 분모를 줄이지 않음.
- 정답 순으로 순위, 이후 관전/답변만 참여. 마지막 1명은 `미탈출` 최종 순위로 종료.
- 연결 끊김은 60초 재접속 허용. 자기 차례 패스, 신규 답변자 선택 제외. 진행 중 입력은 기존 기한 적용. 60초 초과/직접 나가기는 중도 퇴장 및 등수 미부여. 방장 퇴장 시 연결된 가장 빠른 번호로 이전.

## 구현/검증

- HTTP API + 인증된 fetch SSE. 서버가 모든 단계, 마감 시각, 투표와 순위를 판정합니다.
- 세션 토큰은 브라우저 탭의 sessionStorage에 저장하고 Authorization 헤더로만 전송합니다.
- 서버 응답은 본인의 미확인 정체 및 자신의 후보 목록을 제외합니다. 투표자별 선택은 전달하지 않습니다.
- 다른 플레이어의 입력이나 채팅 때문에 작성 중인 폼을 재생성하지 않습니다.
- 테스트: `tests/game.test.mjs`, `tests/server.test.mjs`.
- `dist/index.html`, `dist/app.js`는 UI 체험 전용이며 실제 게임 규칙은 `game.mjs`가 관리합니다.
- 제시어 선정 중 정답 노출을 피하기 위해 채팅을 잠시 비활성화합니다.
